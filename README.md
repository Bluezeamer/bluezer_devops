# bluezer_devops

Agent Skill 集合。每个 skill 一个独立目录，自带说明与开发进度。

## 目录

| Skill | 作用 | 状态 |
|---|---|---|
| [project-tour](skills/project-tour/) | 以拓扑优先的方式为项目生成分层、可展开的阅读导览 | 基线成型，迭代中 |

## 约定

- 每个 skill 位于 `skills/<name>/`，遵循 Agent Skills 规范：`SKILL.md` 为入口，`examples/`、`references/` 按需加载。
- 每个 skill 目录下保留一份 `PROGRESS.md`，记录背景、目标、当前进度与未完成项。
